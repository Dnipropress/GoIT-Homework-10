# Бот-асистент з адресною книгою

Розпакуйте ZIP і виконайте команду в папці проєкту. Потрібен Python 3.9 або новіший. Сторонні бібліотеки не потрібні.

```sh
python main.py
```

| Команда | Дія |
| --- | --- |
| `add Anna 0501234567` | Створити контакт або додати йому номер |
| `change Anna 0501234567 0671234567` | Замінити номер |
| `phone Anna` | Показати всі номери контакту |
| `all` | Показати всі контакти |
| `add-birthday Anna 25.11.2000` | Зберегти або оновити день народження |
| `show-birthday Anna` | Показати день народження контакту |
| `birthdays` | Показати найближчі дні народження й дати привітань |
| `hello` | Отримати вітання від бота |
| `close` або `exit` | Завершити роботу |

Ім’я вводиться одним словом. Телефон має містити рівно 10 цифр, дата має бути дійсною і мати формат `DD.MM.YYYY`. Адресна книга зберігається в пам’яті протягом сеансу.

Команда `birthdays` враховує дні народження від сьогодні до шостого дня включно. Якщо день народження припадає на вихідні, бот показує дату привітання в найближчий понеділок, навіть якщо він поза цим періодом. У невисокосний рік для 29 лютого використовується 28 лютого.
